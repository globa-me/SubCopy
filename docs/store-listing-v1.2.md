# SubCopy — Chrome Web Store Listing (v1.2)

---

## 1. English (`en`) — Default Locale

### Short Description (max 132 chars)
```
Copy YouTube subtitles, save high-resolution thumbnails, and copy public video info in one click.
```

### Full Description
```
SubCopy — YouTube subtitles, thumbnails and video info in one click.

What's new in v1.2:
- High-resolution thumbnail tools: save the best thumbnail YouTube provides or copy it to the clipboard as an image.
- Caption language selector: pick any available subtitle track and copy it.
- All-in-one video info extractor: one click builds a Markdown report with title, channel, duration, views, chapters, hidden tags/keywords, cleaned-up links from the description and the full description.
- YouTube Shorts support.
- Localized in 8 languages: English, Indonesian, Spanish, French, Russian, Arabic, Hindi and Chinese.

How it works:
1. Open a YouTube video with captions or a transcript.
2. Click the SubCopy icon.
3. Choose "With timestamps" or "Clean text".
4. Paste the copied transcript wherever you need it.

SubCopy reads the caption tracks exposed by the active YouTube video and uses packaged fallback extraction methods when needed.

Privacy: SubCopy collects no data. It only reads the captions and metadata of the video in your active tab and writes to the clipboard when you choose to copy. No accounts, no tracking, no ads.

Developed by Gennadiy Zakharov & Ivan Kononov.
```
